Setup Instructions

Run the following commands in PowerShell before running the Python experiments.

winget install --id Python.Python.3.13 -e
if ($?) {
    py -3.13 -m pip install numpy pandas matplotlib scikit-learn seaborn scipy statsmodels
}

If Python is already installed, you can run:

py -m pip install numpy pandas matplotlib scikit-learn seaborn scipy statsmodels
